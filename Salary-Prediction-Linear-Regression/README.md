# Salary Prediction using Linear Regression

## Overview

This project focuses on predicting employee salaries using Linear Regression.

The project applies the Machine Learning workflow learned during the NTI training, starting from data exploration and preprocessing to model training and evaluation.

## Dataset

The dataset contains information about employees, including:

- Age
- Gender
- Education Level
- Job Title
- Years of Experience
- Salary

## Project Steps

1. Data Loading
2. Data Understanding
3. Data Cleaning
4. Exploratory Data Analysis (EDA)
5. Handling Missing Values
6. Handling Duplicates
7. Categorical Encoding
8. Train-Test Split
9. Feature Scaling
10. Linear Regression
11. Model Evaluation
12. Visualization

## Model

Linear Regression was used to predict employee salaries based on the available features.

## Evaluation Metrics

- MAE
- MSE
- RMSE
- R² Score
