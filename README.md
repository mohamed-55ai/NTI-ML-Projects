# NTI Machine Learning Projects

This repository contains practical Machine Learning and Deep Learning projects developed during my NTI training.

Each project focuses on applying core concepts to real-world datasets, spanning data exploration, preprocessing, model training, hyperparameter tuning, and comprehensive evaluation.

## 📂 Projects

| Project | Domain / Type | Main Concepts & Algorithms |
|---|---|---|
| [Salary Prediction using Linear Regression](./Salary-Prediction-Linear-Regression) | Regression | EDA, Data Preprocessing, Categorical Encoding, Feature Scaling, Linear Regression, Metrics (MAE, MSE, RMSE, R²) |
| [Gender Classification using Logistic Regression](./Gender-Classification-Logistic-Regression) | Classification | EDA, Duplicate Handling, Feature Scaling, Logistic Regression, Probability Prediction, Log Loss, Regularization Analysis (C tuning) |
| [Car Price Prediction using Neural Networks](./Car_Price_Prediction_NN) | Deep Learning (Regression) | Feed-Forward Neural Networks (Keras), Nominal/Ordinal Encoding, StandardScaler, Dropout, EarlyStopping |
| [Fashion-MNIST Image Classification (CNN)](./CNN_CIFAR10_Image_Classification) | Computer Vision (Classification) | Convolutional Neural Networks (Conv2D, MaxPooling2D, Flatten, Dense), Fashion-MNIST, Softmax Classification, Accuracy Curves |
| [Penguins Body Mass Prediction](./Ensemble_Method_penguins) | Ensemble Learning (Regression) | Benchmarking Linear Regression vs. Bagging Regressor (Decision Trees) vs. XGBoost Regressor, MAE / RMSE / R² comparison |
| [Breast Cancer Detection](./KNN_breast_cancer) | Classification / Healthcare | KNN with GridSearchCV (5-Fold CV), SVM (RBF), Logistic Regression, Clinical Decision Threshold Optimization (F1-score maximization) |
| [Pumpkin Seeds Classification](./Pumpkin-Seeds-SVM) | Morphological Classification | Support Vector Machines (SVM), Scikit-learn Pipeline, 5-Fold Stratified GridSearchCV (RBF vs. Linear, C & Gamma tuning), ROC-AUC |
| [Sequence Modeling & Forecasting](./RNN%26LTSM%26GRU) | Deep Learning (Time Series) | Recurrent Architectures (SimpleRNN vs. LSTM vs. GRU), Sliding Window Sequence Modeling, Parameter Efficiency & Convergence |
| [Wine Clustering & Dimensionality Reduction](./k_means%26PCA_wine) | Unsupervised Learning | Standard K-Means vs. Bisecting K-Means, Elbow Method (Inertia), Silhouette Score, Principal Component Analysis (PCA 2D projection) |

## 🛠️ Tools & Libraries

- **Programming:** Python 3.x
- **Data Manipulation & Analysis:** NumPy, Pandas
- **Visualization:** Matplotlib, Seaborn
- **Classical Machine Learning:** Scikit-learn, XGBoost
- **Deep Learning:** TensorFlow, Keras
